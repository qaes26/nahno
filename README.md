# منصة نَحْنُ (Nahno) للتطوع | التمثيل الرسمي في جامعة إربد الأهلية
### إعداد: قيس الجازي

بوابة إلكترونية تعريفية وبروتوكول مؤسسي متكامل باللغة العربية (RTL) لتمثيل **منصة نَحْنُ الوطنية للتطوع** داخل صرح **جامعة إربد الأهلية**، بالتعاون مع **عمادة شؤون الطلبة**.

---

## 🌟 أبرز مميزات التحديث والتصميم المؤسسي

1. **تصميم مؤسسي متوافق 100% مع الهواتف الذكية (Mobile Responsive):**
   - واجهة متجاوبة بالكامل لجميع مقاسات الشاشات (الهواتف المحمولة، الأجهزة اللوحية، وشاشات الحواسيب).
   - قائمة تنقل منسدلة وسلسة باللمس (Mobile Drawer Navigation).
   - ضبط دقيق للمسافات وحجوم الخطوط والأزرار لمنع أي انزياح أفقي.
   - نافذة شات بوت ذكية مصممة خصيصاً لتناسب شاشات الهواتف بصورة مريحة وسلسة.

2. **دليل وتعليمات كيفية التطوع خطوة بخطوة للطلبة (بدون أي نماذج استفسارات):**
   - **المرحلة الأولى (التسجيل والارتباط):** إنشاء حساب على `nahno.org`، واختيار "جامعة إربد الأهلية"، وتصفح الفرص المتاحة.
   - **المرحلة الثانية (الحضور الميداني):** الالتزام بالمواعيد، مسح رمز QR الإلكتروني الخاص بالفعالية لتأكيد التواجد، وتمثيل الجامعة بصورة مشرفة.
   - **المرحلة الثالثة (المصادقة والاعتماد):** مصادقة عمادة شؤون الطلبة على الساعات ونزولها في الرصيد، واحتسابها كخدمة مجتمع ومتطلب تخرج معتمد، وتحميل الشهادة الرسمية برمز QR.
   - **الضوابط والشروط:** إتاحة التطوع لجميع الطلبة دون اشتراط أي معدل تراكمي، وتوضيح مقر عمادة شؤون الطلبة لمتابعة أي إجراء ميداني مباشر دون الحاجة لأي نماذج تواصل.

3. **التوثيق الرسمي:**
   - توثيق المشروع رسمياً وبكل فخر باسم: **"إعداد: قيس الجازي"** في التذييل وشريط التوثيق ووثيقة البروتوكول والمساعد الذكي، دون ذكره كمنسق مع المنصة أو الجامعة (حيث أن المنسقية والمتابعة الإدارية من اختصاص عمادة شؤون الطلبة).

4. **شات بوت ذكي مدعوم بـ Groq AI مع تدوير عشوائي للمفاتيح (Random API Key Pool):**
   - تدوير عشوائي وتوزيع أحمال آلي بين 3 مفاتيح Groq API نشطة لتفادي قيود الاستخدام وضمان أعلى سرعة استجابة.
   - نموذج عربي فائق الفصاحة (`allam-2-7b`) مع استرجاع احترافي لأدق التفاصيل.
   - نظام تراجع آمن (Graceful Fallback) لقاعدة المعرفة المحلية عند انقطاع الإنترنت.

## 📁 هيكلية ملفات المشروع

```text
nahno/
│
├── index.html                   # صفحة الويب الرئيسية المتكاملة والمتوافقة مع الهواتف
├── server.js                    # خادم Node.js مع مسار /api/chat وتدوير المفاتيح العشوائي
├── README.md                    # دليل التوثيق والتشغيل
│
├── assets/
│   └── images/
│       └── nahno-logo.png       # شعار منصة نَحْنُ المعتمد
│
├── css/
│   └── style.css                # أنماط وتنسيقات CSS المؤسسية الحديثة المتوافقة مع الموبايل
│
└── js/
    ├── app.js                   # تفاعلات الموقع، حاسبة الساعات، تصفية المسارات، ومعاينة الشهادة
    ├── chatbot.js               # محرك الشات بوت الذكي وقاعدة المعرفة والتدوير العشوائي
    └── protocol.js              # إدارة نافذة البروتوكول الرسمي والطباعة
```

## 🚀 كيفية تشغيل الموقع محلياً

### التشغيل عبر خادم Node.js المحلي:
```bash
node server.js
```
ثم فتح الرابط التالي في المتصفح:
```
http://127.0.0.1:3000
```
